## v1.8 相对 v1.7 的新增与扩展

以下内容在 v1.7 正式版之后进入开发，并由 v1.8 恢复提交重新纳入版本控制；它们才计入 v1.8 阶段，不把恢复回来的 v1.7 基线功能重复算作更新。

### Workshop 与原版文本本地化

- 增加 Workshop / Vanilla 资产文本扫描、翻译队列、批量请求、重试、缓存和进度状态管理。
- 按物品名称、物品说明、载具名称、动作文本和动作提示分别记录翻译，避免单个字段已有中文时跳过同一资产的其他英文字段。
- 增加协议、端点、模型、区域、项目、批量大小、超时和重试次数等翻译 API 设置。
- 增加原生 UI 写入路径，覆盖 `ItemAsset` 名称与说明、`VehicleAsset` 名称、动作文本/提示、物品详情和库存悬停名称。
- 保留已有原版或其他本地化提供的中文文本，避免插件缓存覆盖更合适的原生翻译。

### 背包整理与快捷转移

- 增加背包状态读取、分类/排序规则、布局规划、执行与回滚模型。
- 支持当前页面、全部随身页面、跨页整理、装备保护、快捷栏保留、自动旋转和自定义排序。
- 增加排序预设管理与预设抽屉。
- 增加原生库存界面 Ctrl/Shift 修饰键的同类物品跨容器快捷转移入口。

### 全局快捷键框架

- 在既有菜单开关键基础上，增加统一的快捷键动作注册、Windows 原生键盘检测、输入策略和配置持久化。
- v1.8 阶段接入菜单开关与背包整理动作；后来在 v1.9 扩展的生命条、自动拾取、无限储存等动作不归入本节。
- 增加设置页中的“插件窗口”和“背包整理”快捷键分组及状态展示。

### 配套界面与状态管理

- 为上述新功能恢复焦点提示、可选择控件视觉状态、图标绑定、输入防抖和界面状态保存。
- 恢复 Workshop 翻译进度快照与背包整理状态在菜单中的展示和刷新连接。
- 这些是 v1.8 新功能的配套集成，不代表重新发布 v1.7 已有的筛选、收藏、传送或移动功能。
