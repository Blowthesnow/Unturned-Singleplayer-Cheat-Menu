> 状态：记录本轮源码、测试和文档整理结果。本次只提交并推送代码，不创建标签、发布包或 GitHub Release；插件程序集版本已更新为 `1.9.0`，但没有正式版发布资产。

## v1.9 新增功能

### 自动拾取与无限储存

- 新增受真实单人世界门禁保护的自动拾取：可配置范围、扫描频率、每轮请求数、死亡/菜单暂停、诊断级别，以及白名单/黑名单规则持久化。
- 新增质量过滤和掉落回退保护；拾取失败不会吞掉掉落，玩家主动丢弃的物品会在配置时长内暂时阻止自动回收。
- 新增独立的无限储存窗口：支持物品搜索、批量存入/取出、条目数量和状态展示、持久化保存，以及跨存储配方材料和成品溢出适配。
- 无限储存按资源单位、完整容器和带状态物品区分堆叠语义；无法安全判断的旧条目保守保留，不强制迁移。

### 生命条、悬停详情与交互

- 新增生物生命条 HUD，支持动物/僵尸筛选、伤害后显示、距离/遮挡检查、数量上限和诊断配置。
- 新增物品、弹药、配件、衣物、食品、饮料、医疗和载具的悬停详情；补充弹药兼容性、剩余弹药、品质和状态信息。
- 新增视角方向飞行模式，并保留世界轴模式、水平/垂直速度倍率和关闭穿墙后的安全脱困。
- 背包整理增加背包/背心/上衣/裤子范围开关；整理成功或回滚时同步热键物品坐标，异常时恢复库存和热键状态。

### 全局快捷键与本地化修复

- 新增全局快捷键注册和状态提示，可配置无敌、无限生存、恢复、飞行、穿墙、准星工具、生命条、自动拾取、无限储存、时间、天气和空投动作；新增动作默认未绑定并受单人门禁、输入捕获和冲突检查约束。
- 修复 Workshop/原版本地化快照按字段覆盖的问题；缓存键加入资产类型、GUID、定位键和 schema 版本，避免同名文本串译文串用。
- 扩展 NPC 对话、任务、物件交互和供应商文本扫描，并保护富文本/对话占位符顺序和完整性。

## 恢复范围

## 功能恢复

- 恢复 Workshop / Vanilla 资产文本扫描、翻译队列、批量请求、重试、缓存和进度状态管理。
- 恢复物品名称、物品说明、载具名称、动作文本和动作提示的独立翻译记录，避免某个字段包含中文时错误跳过同一资产的其他英文文本。
