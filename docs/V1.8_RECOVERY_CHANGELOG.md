### 运行时与生命周期

- 用 `PluginRuntimeContext` 和 `PluginRuntimeComposition` 统一持有功能服务、UI、Harmony、事件订阅和销毁顺序，移除旧 `PluginRuntimeHost` 与临时 Driver 路径。
- `RuntimeUpdatePatch` 静态挂接 `Provider.Update`、`MenuUI.Update` 和 `PlayerUI.Update`，逐帧去重后分发 Update/LateUpdate；启动场景切换不再依赖容易被 Unity 销毁的临时驱动对象。
- 所有运行时界面统一归属一个 `PluginUiRoot`，集中管理菜单层、HUD 层、模态层、原生 UI 共存、输入释放和场景引用重建。
- 退出时按事件、Update 桥、输入、移动、UI、小地图、生命条、自动拾取、无限储存、传送、图标、翻译和 Harmony 的顺序幂等清理，单步失败不会跳过后续释放。
- 自动拾取与小地图共享一份附近掉落快照，按两者所需最大半径和最高频率扫描，显示侧不再受拾取质量、白名单或临时禁拾逻辑污染。

### uGUI 架构与交互

- 将巨型 `CheatMenuOverlayUi` 拆分为角色、目录、自动拾取、无限储存、背包工具、交互工具、移动、传送、本地化和世界控制等独立 partial view。
- 新增 presenter/port、页面 ViewHost、活动页缓存、界面状态存储、搜索编辑状态、输入控制、Toast、窗口拖动与几何约束，业务服务不再直接绑死控件生命周期。
- 页面替换先退休旧对象，再避开 Canvas rebuild 延迟销毁，修复同帧销毁导致的新页面引用失效、闪烁和空白。
- 将图标轮询、可选择控件状态刷新和 UI root 维护收口到统一 runtime pump，减少散落的 MonoBehaviour `Update`。
- 输入框保留 draft/commit、Escape、IME 与焦点语义；窗口位置、活动页面、传送子视图和模态栈在重建时保持一致。
- 新增共享 `SystemFontProvider`，枚举并校验支持中文的 Windows 字体，统一供菜单、准星 HUD、生命条和地图提示使用；字体生命周期由根节点集中释放。
- `Prepare-References.ps1` 移除生产 IMGUI 依赖，补充 TextMeshPro/TextCore 引用，并提供经目录校验的 retired-reference 清理开关。

### 小地图与世界雷达

- 新增圆形/方形小地图 HUD，可配置锚点、偏移、尺寸、可视半径、透明度、扫描/探测/渲染频率，并支持拖动、缩放和布局编辑提交。
- 显示本地玩家朝向、同组原生标记、传送点、僵尸、动物、玩家与地面物品；物品支持普通、罕见、稀有、史诗、传说、神话六档筛选。
- 同屏物品先按稀有度、距离和稳定实例 ID 聚合；跨楼层目标使用上下指示和透明度区分，不把不同楼层错误合并。
- 背景状态机支持原生地图裁剪、实时地表、实时高度切片、回退网格和禁用状态；洞穴/建筑遮挡探测带进入/退出延迟，普通薄楼板不会被误判为厚洞顶。
- 实时相机使用独立地形/物件层、像素网格对齐和受控刷新；原生地图、回退网格与禁用状态不会调度场景相机。
- 新增 `Ctrl + 鼠标滚轮` 缩放手势和小地图开关动作；手势经过输入捕获、修饰键和单人世界门禁。
- 自动拾取可分别选择“跟随小地图范围”和“跟随小地图稀有度”，两项默认关闭。

### Workshop 与原版文本本地化

- API Key 配置改为规范化多行值：去空白、去重、保持顺序并限制最多两个 Key。
- 每个 Key 创建独立 worker 设置，通过 `ParallelTranslationDispatcher` 并发消费批次；每个批次只执行一次，取消和异常按原调用链传播。
- 批量大小范围扩展为 `1–100`，小任务会按可用 worker 数重新平衡，避免配置了多个 Key 却只生成一个批次。
- HTTP handler 通过兼容层尝试设置 `MaxConnectionsPerServer`；Unity Mono 抛出 `NotImplementedException` 或 `PlatformNotSupportedException` 时继续初始化，不再导致插件菜单整体无法打开。
- 翻译页保留首行 `+` 和后续行 `×` 控件，并使用垂直滚动布局，增加 Key 输入行不会压缩下面的协议、模型和批量设置。
- 原有按资产类型、GUID、字段定位键和 schema 版本隔离的缓存与 presentation/snapshot 版本通知继续保留。

### 功能修复与兼容

- 自动拾取候选改为消费共享原始索引并在自己的 adapter 中应用范围、质量、规则和临时禁拾；规则选择器遍历 `PlayerInventory.SLOTS` 到 `STORAGE` 前的完整随身页，包含 Hands。
- 自动拾取白名单/黑名单增加独立分页、搜索、背包选择器、持久化失败回滚和诊断状态展示。
- 配置初始化改为事务：关闭 `SaveOnConfigSet`，捕获文件/内存快照，绑定和迁移成功后一次保存；绑定或保存失败时恢复原始字节与内存状态，首次失败不会遗留半成品配置。
- 车辆缩略图彻底移除资产 `Icon2/Icon` 分支，所有车辆统一用生成相机自动取景并强制最高可用 LOD；缓存格式升至 `2`，旧 PNG 保留在磁盘但不会作为新键命中。
- 车辆卡片按照实际纹理宽高更新 `AspectRatioFitter`，避免统一卡片中图像被拉伸。
- 地图传送玩家标记改用游戏原生玩家图标并同步朝向；不可用时才生成圆形回退图标。
- 全局快捷键增加小地图开关与滚轮缩放注册，左右 Ctrl/Alt/Shift/Meta 按统一修饰键处理。
- 现有背包整理、无限储存、生命条、准星交互、移动、传送、筛选、收藏和本地化功能接入新的 presenter/runtime/UI root，不改变单人世界门禁。
