# v1.8 恢复源码更新日志（未发布）

> 状态：仅用于记录当前恢复源码的变更范围。此文档不是正式 Release 公告；本次不会创建标签、发布包或 GitHub Release，也不会修改插件程序集版本、项目元数据或既有项目更新日志。

## 恢复范围

本次提交将此前被重置的功能源码重新纳入版本控制。恢复依据为重置前最后一份可运行插件的反编译结果，并经过当前项目构建、Smoke 测试、Unturned 本机程序集 API 对照和实际游戏功能验证。

## 功能恢复

### Workshop 与原版文本本地化

- 恢复 Workshop / Vanilla 资产文本扫描、翻译队列、批量请求、重试、缓存和进度状态管理。
- 恢复物品名称、物品说明、载具名称、动作文本和动作提示的独立翻译记录，避免某个字段包含中文时错误跳过同一资产的其他英文文本。
- 恢复翻译 API 设置，包括协议、端点、模型、区域、项目、批量大小、超时和重试次数。
- 恢复原生 UI 覆盖路径：`ItemAsset` 名称与说明、`VehicleAsset` 名称、动作文本/提示、物品详情说明和库存悬停名称。
- 恢复“保留已有原版/其他本地化中文文本”的保护逻辑，避免本插件缓存覆盖更合适的原生翻译。

### 背包整理与快捷转移

- 恢复背包整理领域模型、背包状态读取、分类/排序规则、布局规划和执行流程。
- 恢复当前页面、全部随身页面、跨页整理、装备保护、快捷栏保留、自动旋转和自定义排序配置。
- 恢复预设管理与预设抽屉；抽屉采用三列 `112 x 28` 按钮布局。
- 恢复在原生库存界面中使用 Ctrl/Shift 修饰键进行同类物品跨容器快速转移的补丁入口。

### 全局快捷键

- 恢复全局快捷键动作、快捷键管理、Windows 原生键盘检测和输入策略。
- 恢复菜单开关、背包整理动作及其配置持久化。
- 恢复设置界面中“插件窗口”和“背包整理”分组、分隔线和 `24px` 组间距。

### 菜单、筛选、收藏与地图传送

- 恢复物品筛选状态、主分类、来源筛选、枪械射击模式筛选和筛选快照。
- 恢复收藏序列化与不可用/暂未加载资产的兼容处理。
- 恢复地图传送快照、标记类型、标记 UI、颜色与位置数据的持久化兼容。
- 恢复菜单焦点提示、可选择控件视觉状态、图标绑定、输入防抖以及界面状态保存。

### 单人游戏动作与原生交互

- 恢复飞行、穿墙、速度配置和原生移动模拟周期集成，并保留重模拟期间的保护处理。
- 恢复 PointTool 的目标判定、动作闸门、准星 HUD 和指定交互范围覆盖。
- 恢复储物箱、门、发电机、聚光灯、篝火、烤炉、氧气机、安全区和载具进入请求的范围补丁目标。
- 恢复无敌、物品/载具操作、载具缩略图缓存与渲染相关代码。
