# 当前功能与全局快捷键清单

更新日期：2026-08-27  
依据：当前工作区的 `src/UnturnedSingleplayerCheatMenu` 实现（包括尚未提交的自动拾取、无限储存、生命条和本地化功能）。

## 快捷键策略

- 全部操作仍受 `SingleplayerGuard` 限制：只在无 BattlEye 的真实单人世界中运行。
- 快捷键分为“已实现”“应纳入但默认未绑定”“不应做成直接全局操作”三类。
- **默认只保留菜单开关 `End`。** 它是用户发现和配置其他功能的入口。
- 现有的无限储存和背包整理三个默认按键可以保留为兼容预设；新纳入的动作一律初始为“未绑定”，由玩家在全局快捷键窗口中自行设置。
- 未绑定不是无效配置：快捷键注册器需要明确支持 `KeyboardShortcut(KeyCode.None)`，且轮询、原生输入、IMGUI 输入、冲突检查和配置迁移都应跳过它。当前 `ShortcutInputPolicy.IsAllowedShortcut` 会拒绝 `None`，这是落地“默认未绑定”前必须先补齐的基础能力。
- 全局快捷键只执行无参数、语义明确、可立即反馈的动作；需要搜索、数量、目标、位置、网络/API 配置或二次确认的按钮保留在界面内。
- 同一动作只能有一个绑定；与已注册动作冲突时拒绝保存。鼠标左/右键继续禁止绑定，以免破坏游戏操作。

## 全局快捷键动作表

### 已实现

| 动作 ID | 名称 | 当前默认 | 说明 |
| --- | --- | --- | --- |
| `menu.toggle` | 打开或关闭菜单 | `End` | 保留为唯一必需默认快捷键 |
| `infinite-storage.toggle` | 打开或关闭无限储存窗口 | `Ctrl+Keypad0` | 兼容现有设置；用户可改为未绑定 |
| `inventory.arrange.current` | 整理当前容器 | `Ctrl+I` | 兼容现有设置；用户可改为未绑定 |
| `inventory.arrange.all-carried` | 整理全部随身容器 | `Ctrl+Shift+I` | 兼容现有设置；用户可改为未绑定 |

## 不纳入直接快捷键的按钮

以下不是遗漏，而是为了避免误触、无上下文执行或引入额外状态定义：

- 所有带数值、文本、搜索、筛选、分类、数量、颜色、缩略图、速度、距离、API、模型或重试参数的设置。
- 指定物品给予、指定车辆生成、收藏增删、传送点保存/传送/删除、地图点击传送。
- 准星工具的实际执行和删除：继续使用中键；删除继续强制 `Shift+中键`。
- 自动拾取白名单/黑名单增删、诊断清理和性能参数。
- 无限储存的存入、取出、取全部和配方相关操作。
- 背包预览、仅压缩、仅归并、撤销，以及排序/范围/保护选项。
- Workshop 翻译开始、强制重译、停止、缓存重载和 API 配置，避免全局按键造成网络请求或费用。

## 实施顺序

1. 让快捷键系统支持“未绑定”：新增 `IsUnbound` 分支，注册、输入检测、冲突检查和快捷键编辑器均允许 `KeyCode.None`。
2. 将上表“第一批应纳入”逐项接入 `GlobalShortcutManager`，每项复用现有服务方法，不复制业务逻辑。
3. 在全局快捷键窗口按“角色、移动、准星、自动化、世界”分组展示；未绑定项显示“未设置”，并提供录入、清除和恢复默认三个操作。
4. 为每个全局动作补充单人守卫、菜单/输入框捕获门禁、状态提示和冲突测试；飞行、穿墙、自动拾取、无限储存和准星工具还应做一次游戏内开关验收。

## 验收标准

- 新增动作初始均不触发，只有用户录入后才会响应。
- `End` 仍可打开菜单；现有三个兼容预设可用、可清除、可重新绑定。
- 未绑定动作不会被判为配置错误，也不会参与冲突检测或调用原生输入检测。
- 快捷键录入输入框获得焦点时，任何全局动作都不得执行。
- 每个切换动作都在 HUD/状态栏和日志中报告最终状态；无效单人环境必须拒绝执行并说明原因。
- 对已有中键准星交互、原生背包操作和游戏默认左/右键没有回归。
